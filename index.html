Endpoint Reference

1. GET /books

Returns the full array of books currently held in server memory.

curl -X GET http://localhost:3000/books

2. GET /books/:id

Retrieves a single book matching the given integer ID, or 404 if not found.

curl -X GET http://localhost:3000/books/1

3. POST /books

Creates a new book. Requires JSON body with title and author, optional year, genre, and cover.

curl -X POST http://localhost:3000/books \ -H "Content-Type: application/json" \ -d '{"title": "The Picture of Dorian Gray", "author": "Oscar Wilde", "year": 1890, "genre": "Gothic Philosophical", "cover": "https://images.unsplash.com/photo-1543002588-bfa74002ed7e"}'

4. PUT /books/:id

Modifies the specified fields of an existing book by ID.

curl -X PUT http://localhost:3000/books/1 \ -H "Content-Type: application/json" \ -d '{"title": "The Great Gatsby (Centennial Edition)"}'

5. DELETE /books/:id

Deletes a book from memory by ID and returns the removed item.

curl -X DELETE http://localhost:3000/books/2
